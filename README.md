# JobFit AI

JobFit AI — прототип помощника для анализа соответствия резюме вакансии и подготовки честных сопроводительных писем. Проект показывает, как сочетать детерминированные правила и LLM, не позволяя модели приписывать кандидату отсутствующий опыт.

## Задача

При отклике кандидат часто сталкивается с тремя проблемами:

- сложно быстро понять, насколько резюме соответствует вакансии;
- легко пропустить конфликт графика или обязательное требование;
- AI может написать убедительное письмо, но добавить неподтвержденные навыки.

JobFit AI превращает два неструктурированных текста — резюме и вакансию — в понятный отчет с доказательствами и безопасным черновиком отклика.

## Возможности

- рассчитывает ориентировочную оценку соответствия;
- находит совпавшие и недостающие навыки;
- сопоставляет требования вакансии с фактами из резюме;
- обнаруживает конфликт полной и частичной занятости или офисного формата;
- проверяет черновик письма и отмечает неподтвержденные заявления;
- формирует сопроводительное письмо на основе найденных фактов;
- экспортирует результат в JSON;
- работает в демонстрационном режиме без API-ключа;
- поддерживает расширенный анализ через OpenAI Responses API.

## Как устроен проект

```text
Ввод резюме и вакансии
        │
        ├── Демо-режим: словарь навыков + правила
        │
        └── AI-режим: OpenAI Responses API
                     │
                     ▼
 Структурированный MatchReport
        │
        ├── оценка соответствия
        ├── навыки и пробелы
        ├── требования и доказательства
        ├── риски графика
        └── сопроводительное письмо
```

Детерминированное ядро позволяет запустить демонстрацию без внешних сервисов и покрывается автоматическими тестами. AI-режим предназначен для более гибкого разбора формулировок.

## Быстрый запуск через Docker

Требуется Docker Desktop или Docker Engine.

```bash
git clone https://github.com/Daniil-topor/jobfit-ai.git
cd jobfit-ai
docker build -t jobfit-ai .
docker run --rm -p 8501:8501 jobfit-ai
```

Откройте [http://localhost:8501](http://localhost:8501) и нажмите **«Загрузить пример»**. Для демонстрационного режима API-ключ не нужен.

## Локальный запуск

Требуется Python 3.11 или новее.

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

### macOS и Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

## AI-режим

1. Откройте боковую панель.
2. Выберите **OpenAI API**.
3. Введите свой API-ключ и название доступной модели.
4. Добавьте резюме и описание вакансии, затем запустите анализ.

API-ключ используется только для текущего запроса и не записывается в репозиторий или конфигурационные файлы.

## Тесты

Тесты ядра не требуют Streamlit, OpenAI SDK или доступа к сети:

```bash
python -m unittest discover -s tests -v
```

Проверяются совпадения и пробелы в навыках, конфликт графика, неподтвержденные заявления, использование фактов в письме и корректная пунктуация.

## Структура репозитория

```text
app.py                  интерфейс Streamlit

jobfit/sample_data.py   демонстрационные данные
tests/                  автоматические тесты
```

## Безопасность и ограничения

- приложение не отправляет отклики и не изменяет резюме автоматически;
- API-ключ не сохраняется приложением;
- демо-режим использует ограниченный словарь навыков и не заменяет решение рекрутера;
- AI-режим может ошибаться, поэтому итоговые факты необходимо проверять;
- оценка соответствия является ориентиром, а не прогнозом решения работодателя.
