# JobFit AI

Прототип помощника для анализа вакансий и подготовки честных откликов.

Пользователь вставляет резюме и описание вакансии. Приложение:

- выделяет совпавшие и недостающие навыки;
- проверяет отдельные требования;
- обнаруживает конфликт графика и формата работы;
- отмечает навыки в письме, которые не подтверждаются резюме;
- готовит черновик сопроводительного письма;
- экспортирует структурированный отчет в JSON.

## Почему это AI-проект

В приложении есть два режима:

1. **Демо без API** — детерминированный анализ, который можно запустить сразу.
2. **OpenAI API** — анализ неструктурированного текста через Responses API с обязательным правилом: не добавлять сведения, которых нет в резюме.

API-ключ вводится в поле с типом `password`, используется только для текущего запроса и не записывается в репозиторий.

## Быстрый запуск

### Docker

Требуется установленный Docker Desktop.

```powershell
docker build -t jobfit-ai .
docker run --rm -p 8501:8501 jobfit-ai
```

Откройте [http://localhost:8501](http://localhost:8501). Для демонстрации API-ключ не нужен.

### Локально на Windows

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

После запуска откройте адрес, показанный Streamlit, и нажмите **«Загрузить пример»**.

### Локально на macOS или Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

## AI-режим

Переключитесь на **OpenAI API**, укажите API-ключ и название модели. Ключ находится только в памяти текущей сессии и не записывается в файлы. Демо-режим полностью работает без внешних сервисов.

## Тесты ядра

Тесты не требуют Streamlit, OpenAI SDK или API-ключа:

```powershell
python -m unittest discover -s tests -v
```

## Структура

```text
app.py                 интерфейс Streamlit
Dockerfile             готовый контейнер приложения
jobfit/analyzer.py     детерминированное ядро
jobfit/ai_client.py    интеграция OpenAI Responses API
jobfit/models.py       модели результата
tests/                 автоматические тесты
```

## Ограничения

- Демо-режим использует словарь навыков и простые правила, поэтому не заменяет оценку рекрутера.
- AI-режим может ошибаться; пользователь должен проверять итог перед отправкой.
- Приложение не отправляет отклики и не изменяет резюме автоматически.
